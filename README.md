# Vaccination Density Analysis — Arequipa

Spatial and statistical analysis of the vaccinated population in the department of Arequipa, Peru.

[![Live presentation](https://img.shields.io/badge/View_Presentation-Open-20c997?style=for-the-badge)](https://vninamore.github.io/trabajo_final/)

## Objectives

- Analyze vaccination totals by province
- Compare population groups
- Explore unvaccinated population patterns
- Visualize spatial density and statistical distributions

## Technologies

`R` · `R Markdown` · `Shapefile` · `Spatial Analysis` · `Data Visualization`

## Data products

The repository includes geographic layers, tabular datasets, analytical scripts and the rendered presentation.
